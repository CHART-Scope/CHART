# Docs internal archive

This folder stores internal, historical, or review-oriented documentation that
should not be published on the MkDocs site.

The public documentation source for MkDocs remains under `docs/`.

## Archived from the docs site (11 Nov 2026)

Development-era documents, kept for history and modelling work:

- `vra-integration-plan.md`: the VRA proposal (21 Oct 2026) and its
  implementation log; the current reference is `docs/vra.md`.
- `system-architecture-and-requirements.md`: requirements and capacity
  targets written in October 2026.
- `health-survey-exploration-guide.md` and `health-survey-column-map.csv`:
  guidance for modellers preparing restricted DHS/NFHS survey data, and the
  draft survey-column to model-field map.
- `health-input-contract.md`: the proposed schema for model health inputs.
